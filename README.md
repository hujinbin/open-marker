# Open Marker

数据标注平台，基于 Vite + React 标准脚手架。前端在本仓库，后端在 `E:\gitee\jue`。

## 启动

使用 Node.js 22.12+ 或 24，运行 `npm ci`、`npm run dev`。构建运行 `npm run build`，检查运行 `npm run lint`。

复制 `.env.example` 为 `.env.local`，设置 `API_PROXY_TARGET` 为本地 jue 后端地址（默认 `http://127.0.0.1:3000`）。后端按原项目方式启动，并保证 MongoDB 可用。生产部署时将 `/api` 反向代理到 jue，或构建前设置 `VITE_API_BASE`。路由使用 hash，刷新不需要额外的 history fallback 配置。

## 使用流程

1. 使用惊觉账号登录；新用户可以通过图形验证码注册。
2. 创建文本分类或图像检测项目，设置标签集。
3. 在数据集页面粘贴内容，或导入 TXT / JSONL 文件。TXT 每行一条；JSONL 每行形如 `{"content":"待标注文本或图片地址"}`。
4. 可按已注册手机号添加标注员、审核员，在任务详情中分配标注员。
5. 文本支持多标签分类；图像支持拖动绘制矩形框、删除重画、无目标确认。保存草稿后可继续编辑，提交后等待审核。
6. 审核员通过或填写修改意见驳回；驳回后标注员重新提交。
7. 项目负责人导出已通过数据为 JSONL。图片框包含 `x/y/width/height`，均为相对图片宽高的 0–1 比例。

项目负责人可标注、审核、导出及归档；标注员只能修改分配给自己的任务；审核员可审核当前项目。所有项目成员可查看项目数据。基础版本允许负责人自审。

## 当前范围

- 数据真实保存在后端 MongoDB 的 `annotationProjects` 集合。
- 每项目最多 500 条，样本总大小最多 6 MB；单文本最多 20,000 字符，单次文件最多 5 MB。
- 图片仅导入 HTTP(S) 地址，浏览器直接加载图片；暂不提供图片文件存储服务。
- 项目列表最多返回最近 100 个；操作记录保留最近 200 条。
- 使用版本号防止并发覆盖；出现冲突时点击重新加载，再编辑提交。
- 归档仅隐藏项目并保留数据库记录，当前暂无前端恢复入口。
- AI 预标注、音视频、多边形/分割、数据集版本管理、多级质检和 COCO/YOLO 导出尚未实现。

## 验证

前端执行 `npm run build` 和 `npm run lint`。

后端在 jue 执行 `node scripts/test-annotation.cjs` 和 `node scripts/test-annotation-api.cjs`。后者强制使用本机 MongoDB 的临时 `annotation_test_*` 数据库，测试结束自动清除，不连接业务数据库。

本次已验证浏览器登录、项目创建、文本导入、标注、驳回重提、审核通过、导出触发，以及图像绘框和刷新回显。
